# ChatGPT 提示词优化（独立版）

只做一件事：**把输入框里的提示词，通过官方"临时聊天"自动改写得更清晰，然后回填给你确认**。
本地自用、零依赖、后台驱动、无遮罩、完全可见。数据只存本机。

仓库地址：`https://github.com/TTxxtt/chatgpt-optimize`（私有）

## 目录结构

```
chatgpt-optimize/
├── README.md       ← 本文件（使用说明）
├── .gitignore
└── src/            ← 扩展源码（加载这个文件夹）
    ├── manifest.json
    ├── background.js   优化引擎（临时聊天 + scripting 遥控 + SSE 抓取）
    ├── content.js      页面按钮/确认条/取消还原
    ├── content.css
    ├── popup.html/js/css  设置（模式 + 双模板）
    └── icons/
```

## 怎么用（三选一）

1. Chrome 打开 `chrome://extensions`，edge打开`edge://extensions/`
2. 打开 **开发者模式**
3. 点 **加载已解压的扩展程序** → 选择本仓库的 `src` 文件夹
4. 打开/刷新 `chatgpt.com` → **输入框下方出现「✨优化」**



## 日常使用

1. 在 ChatGPT 输入框写好内容 → 点「✨优化」（或 **Alt+O**）
2. 自动**前台打开官方临时聊天**（`?temporary-chat=true`，**不留历史**）——你可以实时看到改写过程
3. 按钮上实时显示进度：`① 打开临时聊天 → ② 等输入框 → ③ 写模板 → ④ 发送 → ⑤ 等回复 → ⑥ 回填`
4. 对话结束 → 自动**切回原页面**，结果已填入输入框，顶部确认条：
   - **回车 = 确认**（保留改写结果）
   - **Esc = 还原**（恢复你的原文）
5. 运行中：点「⏳…（点击取消）」或按 Esc = 取消（关闭临时聊天 + 还原原文）
6. ChatGPT 正在回复时点优化会提示"请等回复结束后再优化"

弹窗（点工具栏图标）可设置：**Instant/Thinking 模式**、**双模板编辑**（新对话模板 / 对话中模板，`{{prompt}}`+`{{firstUser}}`/`{{lastUser}}`/`{{lastAssistant}}`，各 2000 字符）。
弹窗里还有**诊断模式**开关：打开后点优化不出结果，而是把当前页面的按钮/输入框状态写成报告（复制到剪贴板），用来排查选择器失效。

## v1.1.0 更新（针对网页版改版后"回复了但没回填"）

| 环节 | 修复 |
|---|---|
| 结果捕获 | SSE 解析改为**增量帧累加器**（新版接口用 `{"p":"/message/content/parts/0","o":"append","v":"…"}` 方式推送，旧的"只认整段"解析器会一无所获） |
| 发送确认 | 用 fetch hook 里的 `__optSseStarted` 作"确实发出去了"的信号（原版同款），不再靠"输入框变空/按钮消失"猜测；发送按钮改为**等它渲染出来再点**（最多 8 秒），30 秒内没生成迹象也不直接判失败 |
| 回填 | **后台直接注入写入发起页输入框**（原版同款 `pasted` 通道），不再只依赖 `sendResponse`；写入前比对输入框是否仍是原文，避免冲掉新输入 |
| 投递兜底 | 结果同时写 `chrome.storage.local`，发起页轮询 + 消息双通道；service worker 被回收也不会丢结果 |
| 页面刷新 | 重新打开 ChatGPT 后若输入框为空且 10 分钟内有未领取的结果，自动补填 |
| 救援 | 优化失败时临时聊天页**保留**，右下角「↩ 填回原页面」一键把那条回复填回发起页 |
| 过程可见 | 按钮实时显示 ①~⑥ 步骤与等待秒数，失败原因直接写在按钮/提示里 |

## 常见问题

| 问题 | 处理 |
|---|---|
| 找不到输入框提示 | 确认在对话页；弹窗会把诊断复制到剪贴板，发给我修正选择器 |
| 更新后不生效 | chrome://extensions 里点扩展的刷新 → 重开 ChatGPT 页面 |
| 回复出来了但没回填 | 去临时聊天页点右下角「↩ 填回原页面」；再不行打开弹窗的诊断模式把报告发我 |
| 想恢复出厂 | 弹窗里"恢复默认"模板；清空扩展数据即可 |

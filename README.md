# ChatGPT 提示词优化（独立版）v1.0.0

只做一件事：**把输入框的提示词通过"官方临时聊天"自动改写得更清晰，然后回填给你确认**。
本地自用、零依赖、原版同款架构。数据只存本机。

## 流程（完全可见）

1. 输入内容 → 点输入框下方的 **✨优化**（或 **Alt+O**）
2. **前台打开官方临时聊天**（`chatgpt.com/?temporary-chat=true`，**不留历史**）——你可以实时看到它打开、发送改写任务、生成回答
3. 对话结束 → 自动**切回原页面**，结果已填入输入框，顶部出现确认条：
   - **回车 = 确认**（保留改写结果）
   - **Esc = 还原**（恢复你的原文）
4. 运行中可点「⏳优化中…」或按 **Esc 取消**（关闭临时聊天 + 还原原文）

## prompt 里融入了什么（对齐原版）

- **模板**（弹窗可编辑/恢复默认）：
  - 新对话模板：只有 `{{prompt}}`
  - 对话中模板：`{{prompt}}` + `<conversation_context>`（首条用户消息 / 最后用户消息 / 最后助手回复正文，各 **2000 字符**，从真实对话提取）
- 无对话历史 → 用新对话模板（不带上下文）
- 思考模式（Thinking）不加任何字，**纯粹把临时聊天切到 thinking 模型**

## 加载（Chrome）

1. `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选本文件夹
2. 打开/刷新 `chatgpt.com` → 输入框下方出现「✨优化」

## 权限说明

- `storage`（设置/模板）
- `scripting`（遥控临时聊天页执行填文本/抓取）
- 无 `downloads`、无任何云服务
